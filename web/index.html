ABOUT THE RESEARCH

What this system measures

The interface inspects monthly land-cover predictions derived from Sentinel-1 radar observations and a frozen nine-class segmentation model. It is a retrospective 2021 study, not a live satellite feed or surveyed ground-truth detector.

Source attribution: SARScope, developed by Keyur Chaudhari, provides the trained model, original data processing and saved results. This study interface adds a distinct view of class composition and changes; individual contributions must be described accurately.

Model benchmarks: 74.17% overall accuracy and 42.39% mean IoU on held-out Dynamic World-derived weak labels. These do not establish independent performance in a new location.
